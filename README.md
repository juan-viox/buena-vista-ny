# Buena Vista Restaurant & Bar — Cinematic Site

Premium scroll-driven cinematic website for Buena Vista Restaurant & Bar (buenavistany.com) — "Spain Meets Latin America." Two Manhattan locations: Hell's Kitchen & East Village.

Built with the VioX AI cinematic-sites pipeline: scroll-driven video hero (121 frames, Seedance 2.0), GSAP 3.12.5, AI-generated editorial imagery (Gemini), ElevenLabs voice concierge.

- `site/` — deployable static site (single index.html + assets)
- `project.json` — build contract/state
- `competitive-report.html` / `proposal.html` / `brand-card.html` — Phase 0/1 deliverables

Deployed on Vercel, `outputDirectory: site`.
